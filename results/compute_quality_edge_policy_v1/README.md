# Edge policy：计算约束 FP4 最终结果

独立全层校准、开发轨迹、验证选参及 16 个最终种子测试已完成。平均误差改善未通过配对 95% 置信区间门槛；四档均未超过 FP8。因此本轮不继续扩展 Nano，不宣称动作任务成功率提高或推理加速。

固定条件：Cosmos3 Edge a9d944e，35 steps，policy_observe 开发、policy_table 验证与最终测试，保持原任务实际 CFG、输入与生成投影范围；PRO 6000 GPU0/3，Graph、debug off、shared-calibration。最终种子 101001–101016；仅为现有场景的新种子测试。

## 未通过的验收项

1.25× 相对本档对照：

- 视频 LPIPS 平均差值 -0.017253，95% CI [-0.056195, 0.010882]；最差种子退化 +0.076410。
- 动作相对 L2 平均差值 -0.029105，95% CI [-0.188374, 0.135333]；最差种子退化 +0.677234。
- 平均视频 SSIM/L2 和动作 RMSE 改善，但两个置信区间上界均大于 0。

在 1.5× 上限沿用同一配置，相对更高预算对照的动作 L2 差值为 -0.078902，95% CI [-0.190757, 0.042169]，仍未通过。不能仅凭平均值宣布成功。

## 选参修正与证据保留

原始验证选参按档位分别进行，冻结了 b1.5_refined。之后发现较低预算 b1.25_refined 在所有验证输出指标、MMA 和量化权重存储上均更优。在最终指标文件生成及读取之前，于 2026-09-12 17:50:07 UTC 单独冻结了 [validation_envelope.json](validation_envelope.json)，允许 1.5× 上限沿用这个已验证配置。

原始最终推理作业没有修改或重跑；高预算候选的完整结果保留在 [original_final_report.json](original_final_report.json)，原始选参见 [original_frozen_jobs.json](original_frozen_jobs.json)。[final_report.json](final_report.json) 仅应用提前冻结的验证包络，不根据最终结果重新搜索或选参。两份报告均未通过同预算门槛。选参工具已正式支持较高预算沿用较低预算最优配置，并用回归测试检查最终作业去重。
